# super-mem v0.1.0

The first packaged release of super-mem provides a local, Git-aware memory engine for coding agents, a CLI and MCP server, and reference integrations for Codex, Claude Code, OpenCode, and Pi.

Highlights:

- Evidence-first SQLite storage with immutable events, revision history, feedback, and provenance.
- Repository, workspace, namespace, branch, commit, dirty-state, and file-content applicability checks.
- Deterministic bounded recall through exact, lexical, diagnostic, entity, artifact, and recency channels.
- Automatic prompt, command, tool, test, file, compaction, and checkpoint capture through reference adapters.
- Atomic, integrity-checked snapshot export and empty-store import.
- Native binaries for Linux x86-64, Windows x86-64, macOS Apple Silicon, and macOS Intel.

Each binary archive is built and smoke-tested on its native architecture. `SHA256SUMS` covers every archive, and GitHub records build-provenance attestations for the release assets.

The macOS binaries are not Apple Developer ID-signed or notarized, and the Windows binary is not Authenticode-signed. Review the checksum and provenance before approving an operating-system warning. See the [installation guide](https://github.com/Limme-swe/super-mem/blob/v0.1.0/docs/installation.md) for platform-specific instructions.

This is a pre-1.0 release. Back up the database with `supermem export` before upgrading across minor versions.
