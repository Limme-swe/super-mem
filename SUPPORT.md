# Support

super-mem is in early development. Interfaces and storage behavior may change before 1.0.

## Where to ask

- Read the [README](README.md) and [integration guide](docs/integrations.md) first.
- Use the [question form](https://github.com/Limme-swe/super-mem/issues/new?template=question.yml)
  for installation, configuration, and design questions.
- Use the [bug form](https://github.com/Limme-swe/super-mem/issues/new?template=bug.yml) for a
  reproducible defect.
- Use the [integration form](https://github.com/Limme-swe/super-mem/issues/new?template=integration.yml)
  for Codex, Claude Code, OpenCode, Pi, or another MCP client.
- Use the [feature form](https://github.com/Limme-swe/super-mem/issues/new?template=feature.yml) for
  focused proposals.

Include the super-mem version or commit, operating system, harness version, and the smallest useful
reproduction. Remove credentials, private source, repository paths, and sensitive memory content.

## Security

Do not report vulnerabilities in a public issue. Follow the private process in the
[security policy](SECURITY.md).

Support is provided by the community on a best-effort basis; response times are not guaranteed.
